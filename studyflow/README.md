# StudyFlow

A prototype web app for adaptive learning, progress tracking, and AI-assisted study recommendations.

## Structure

- `assets/` - static files
- `pages/` - HTML views
- `sass/` - styling sources
- `js/` - JavaScript logic and API integrations
- `docs/` - documentation and planning

## Setup

1. Use a static server or open `index.html` in the browser.
2. Add API keys to `.env` if needed.
